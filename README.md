## 🎯 How to Play

| Control | Action |
|---------|--------|
| ⬅️ **Left Arrow / A** | Move ball left |
| ➡️ **Right Arrow / D** | Move ball right |
| 📱 **Touch/Swipe** | Mobile controls |
| **Spacebar** | Restart game |

**Objective:** Avoid obstacles and survive as long as possible!

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ installed
- npm or yarn package manager

### Installation

```bash
# Clone the repository
git clone https://github.com/zainabhina05-png/How_Ball.git

# Navigate to project directory
cd How_Ball

# Install dependencies
npm install
# or
yarn install
```

### Running Locally

### Running Locally

```bash
# Start development server
npm run dev
# or
yarn dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to play!

### Build for Production

```bash
# Create optimized production build
npm run build

# Start production server
npm start
```

## 📂 Project Structure

```

├── app/                    # Next.js App Router
│   ├── page.tsx           # Main game page
│   ├── layout.tsx         # Root layout
│   └── globals.css        # Global styles
├── components/
│   ├── game/              # Game components
│   │   ├── Ball.tsx       # Player ball

│   │   ├── Scene.tsx      # 3D scene setup

│   │   ├── GameManager.tsx
```
